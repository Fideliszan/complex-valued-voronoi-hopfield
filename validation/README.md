# Scientific validation records

This folder contains reference-run environments, coordinate-energy audits, boundary checks, and separately recorded hosted measurements. [Validation](../docs/VALIDATION.md) explains the scope and tolerances. The checks are independent of manuscript sources.

| File | Content |
|---|---|
| `manifest.json` | SHA-256 hashes of frozen data, alphabet coordinates, and figure source data |
| `publication_run.json` | Consolidated historical configuration, environment, durations, benchmark summary, and local comparison records |
| `notebook_execution.json` | Full local notebook execution records and code-cell hashes |
| `*_coordinate_audits.csv`, `*_coordinate_audit_summary.json` | Per-trajectory energy audits and their totals |
| `boundary_validation.csv` | Benchmark decisions at nearest-neighbor midpoints and zero |
| `query_manifest.json` | Original SHA-256 hashes of the 32 regenerated query arrays |
| `hosted/` | Separate Colab trial data, timings, audits, and comparisons; identical duplicate saturation history is represented by its comparison record |
| `colab_v1.0.2/` | Historical public-download Colab validation tied to its recorded source revision |

`geometry_check.json` is regenerated by `scripts/verify_geometry.py` and ignored by Git. New run outputs belong under `runs/`. Historical timings and audits are reference evidence; they are not replaced by routine checks.
