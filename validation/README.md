# Scientific validation records

This folder contains publication-run environments, per-coordinate energy audits, benchmark boundary checks, and a separate full hosted replication in `hosted/`. See [Validation](../docs/VALIDATION.md) for scope and tolerances. `manifest.json` records SHA-256 hashes of frozen scientific inputs; the hosted manifest covers preserved hosted measurements. No browser session exports or account identifiers are required for reproduction.

| File | Content |
|---|---|
| `manifest.json` | SHA-256 of the frozen publication data, alphabet coordinates, and figure source data |
| `publication_run.json` | Publication-host run records (configuration, environment, durations), the benchmark summary, and the local notebook comparison; each key is a former standalone file, unchanged |
| `notebook_execution.json` | Full local execution record of the current notebooks (code-cell hashes, durations) |
| `*_coordinate_audits.csv`, `*_coordinate_audit_summary.json` | Per-trajectory energy audits and their totals |
| `boundary_validation.csv` | Benchmark decisions at nearest-neighbor midpoints and zero |
| `query_manifest.json` | SHA-256 of the 32 publication query files (regenerated by every run; the files are in the v1.0.2 release) |
| `compilation.json`, `figure_typography.json` | Manuscript compilation and figure-font records |
| `hosted/` | Full Colab replication: raw trial data, timings, audits, and comparison records. The hosted saturation history was identical to the publication history, so only its comparison record is kept |

`geometry_check.json` is rewritten by `scripts/verify_geometry.py` on every check and is not tracked.

The [direct v1.0.2 Colab validation](colab_v1.0.2/README.md) records execution of all four public GitHub-linked notebooks, including their setup path, numerical comparisons, figure checks, and evidence limitations.

The [Overleaf validation of the updated ZIP](overleaf_colab_validated_v1.0.2/README.md) records the new project link, successful compilation, preservation of all five figures, and inclusion of the Colab records.

Final checks cover the [exact final identified ZIP](overleaf_final_v1.0.2/README.md) and the separate [anonymous TNNLS review copy](tnnls_anonymous_v1.0.2/README.md).

The [AI-disclosure Overleaf validation](overleaf_ai_disclosure_v1.0.2/README.md) confirms 14 pages, zero errors and warnings, and the exact declaration on page 13. This record is included in the final complete delivery ZIP.
